# ICOMzero 中文设置教程

[返回项目首页](../README.md) · [English user guide](USER_GUIDE.md) · [下载最新版](https://github.com/unagisan69/ICOMzero/releases/latest)

本教程适用于 **ICOMzero 0.16.7 及以后版本**，以 **IC-7300MK2** 为例。应用界面目前使用英文，下面保留屏幕上的英文菜单名称，并附中文说明；本教程不代表应用已经支持中文界面。

ICOMzero 在运行原厂 M5Stack Debian 系统的 **Cardputer Zero** 上，直接通过网络连接电台。主要功能包括收听、频谱/瀑布图、CW 接收解码，以及 FT8 接收、发射和通联日志。

## 安装

1. 将 Cardputer Zero 连接到 Wi-Fi。
2. 在启动器中打开 **App Store**，搜索 **ICOMzero**，或输入分享码 **ICMZ**。
3. 选择 **Install**，安装后从 **APPLaunch** 启动 ICOMzero。

建议先让 Cardputer 和电台处于同一局域网，完成本地收听测试后再配置外网连接。

支持直接联网的电台包括 IC-705、IC-7300MK2、IC-7610、IC-7760、IC-7850/7851、IC-905、IC-9700、IC-R8600，以及 Kenwood TS-890S。**IC-7300MK2 已经过实机测试；其他机型仍需更多实机验证。IC-R8600 仅接收。原版 IC-7300 不等于 IC-7300MK2，不能使用本应用直接通过网口连接。**

## 电台网络设置

在 IC-7300MK2 上进入 **MENU → SET → Network**：

1. 让电台接入路由器，记下其局域网 IP 地址。建议在路由器中为电台保留固定的 DHCP 地址，避免地址变化后连接失败。
2. 确认子网掩码、默认网关等设置符合当前网络；外网访问及校时需要正确的网关设置。
3. 在 **Remote Settings** 中启用 **Network Control**。
4. 在电台上配置远程用户账号和密码，稍后在应用中填写相同信息。不要使用 GitHub、Cardputer 的 SSH 或日志网站账号代替电台账号。
5. 如果没有自行修改端口，保留以下默认值：

| 电台端口 | 协议 | 用途 |
| --- | --- | --- |
| 50001 | UDP | 控制连接（Control） |
| 50002 | UDP | 串口/CAT 控制（Serial） |
| 50003 | UDP | 音频（Audio） |

局域网内使用无需配置互联网端口转发。请参考电台自身的说明书完成网络菜单操作。

## 在应用中添加电台

主菜单有 **Radio**（收听）、**FT8**、**Log**（日志）和 **Settings**（通用设置）。电台连接信息在主菜单设置中管理，不在 Radio 的操作设置中修改。

1. 打开 **Settings → Radios**。
2. 选择已有配置并进入 **Edit connection**，也可以新增或克隆配置。为配置取一个易辨认的名称，例如 `7300 Local`。
3. 填写下表内容。
4. 返回该电台的配置菜单，选择 **Use this radio**，使 Radio 和 FT8 都使用这个配置。

| 屏幕字段 | 如何填写 |
| --- | --- |
| **Host** | 电台 IP 或主机名，例如 `192.168.1.100`；不要填写网页 URL |
| **Control port** | Icom 默认 `50001` |
| **Username** | 电台上设置的远程用户名 |
| **Password** | 对应的电台远程密码 |
| **Radio** | 可选 **Auto (Icom)**；使用自定义电台名称时，也可以明确选择 **IC-7300MK2** |
| **Audio port** | TS-890S 使用的音频端口，默认 `60001`；Icom 的后续通道由协议协商，不要把此字段误当作需要手动填写的 Icom 50003 |
| **Login** | 与电台账号类型匹配的 **User** 或 **Admin** |

**F/X** 或方向键选择字段，**Enter** 编辑或保存，**Esc** 取消当前编辑或返回。**Backspace** 删除一个字符，**Del** 清空文本字段，**SYM+B** 输入句点 `.`。

可分别建立本地和远程配置，使用 **Use this radio** 切换。克隆后修改 IP 即可保留其他连接信息。切换配置前先退出 Radio/FT8。

TS-890S 用户应选择对应机型，并根据电台 KNS 设置填写账号、**TCP 60000** 控制端口和 **UDP 60001** 音频端口；不要套用上面的 Icom 端口表。

## 收听与操作

回到主菜单，选择 **Radio**，按 **Enter** 开始收听。连接成功后会显示频率、接收状态、频谱和瀑布图。

| 按键 | 功能 |
| --- | --- |
| **Enter** | 开始/停止收听 |
| **Z / C** | 向下/向上调谐，长按连续调谐 |
| **B** | 选择波段，Z/C 选择后按 Enter 确认 |
| **S** | Radio 操作设置：波段、步进、模式、CW 解码和音调 |
| **M** | 切换 USB / LSB |
| **Fn+F / Fn+X** | 放大/缩小频谱和瀑布图：1×、2×、4×、8× |
| **Fn+S / Fn+D** | 减小/增大音量；可一直按住 Fn，再连续按 S 或 D |
| **Fn+A** | 静音/取消静音 |
| **N** | 切换电台降噪，需机型支持 |
| **T** | 启动自动天调，需机型支持；**会短暂发射** |
| **W** | 开关 CW 接收解码 |
| **Tab** | 显示快捷键帮助 |
| **Esc** | 返回主菜单 |

在 **S → Tuning step** 中按 Enter 循环选择 **1000 / 500 / 100 Hz**，步进按电台配置保存。音量和静音状态也会保存。

缩放围绕当前调谐频率，1× 是原来的最宽视图。它只放大电台已提供的数据，不改变电台频率或增加真实频谱分辨率。改变倍率时，瀑布历史重新开始，避免不同尺度混在一起。

## CW 接收解码

先在 Radio 中找到清晰的 CW 信号，再按 **W**。此操作不会改变电台当前的模式、频率或滤波器；如果在 LSB/USB 中听得更清楚，可以保持该模式。

- **S → CW tone** 选择 **Auto** 或指定音调，用于多个信号同时存在时锁定目标。
- **F/X** 向上/向下逐行滚动 CW 历史，长按可连续滚动；回到底部后恢复跟随新文字。
- **Fn+F/Fn+X 在 Radio 中用于缩放**，不用于滚动 CW 历史。
- **Fn+A** 可以关闭扬声器声音，不会停止解码。

CW 解码仅接收，不会自动发报或记录 CW QSO。相邻电台干扰、RTTY、衰落或不规则手键发送可能导致错误；优先选择单个清晰信号，并用较小调谐步进调整。

## FT8 设置与通联

**进入 FT8 前，请确认使用合法呼号、合适的天线和发射设置。FT8 确认波段后及切换波段时，会在支持的机型上启动自动天调，期间可能短暂发射。**

1. 主菜单选择 **FT8**。如果当前频率不是预设 FT8 频率，应用会要求先选波段。例如 **40m 为 7.074 MHz**，**20m 为 14.074 MHz**。已有正确的 FT8 频率会保留。
2. 按 **Tab → Settings**，填写自己的电台信息：

| 字段 | 说明 |
| --- | --- |
| **Call sign** | 你自己的合法呼号，不要使用示例或他人的呼号 |
| **Grid / region** | 你的 **Maidenhead 网格定位符**，4 或 6 个字符，例如 `OM89`；这里不是国家代码、省份简称或 IARU 大区编号 |
| **TX audio Hz** | 建议先用 **Auto**，回复时跟随对方解码的音频偏移 |
| **TX level %** | 发射音频电平，范围 10–80%，默认 50%；不是射频功率百分比 |
| **TX power W** | 电台的标称射频功率设定，单位 W；初次测试建议从较低功率开始，并观察电台自身仪表 |
| **CQ period** | 主动 CQ 使用的偶数/奇数时隙；回复对方时应用自动使用相反时隙 |
| **QSO beep** | 成功保存 QSO 后是否提示音 |
| **Hide previous contacts** | 是否隐藏当前波段中已完成过 FT8 通联的电台 |

3. 确认设备时钟已通过网络同步，等待天调完成。
4. 接收解码没有扬声器音频，这是正常行为。列表以消息文字为重点，网格后显示较小的信号报告；右侧是国家/地区估计。
5. **F/X** 或 **Fn+F/Fn+X** 在 FT8 页面中上下选择解码行。选中对方后按 **Enter** 回复；选中状态会清除并回到最新消息。没有选中行时，不要把 Enter 当作收听开关。
6. 主动呼叫时打开 **Tab → Call CQ**。选中行时，这一项显示 **Reply / continue**，会继续该联系的当前阶段。
7. 需要停止时选择 **Tab → Stop Transmit**，或按 **Esc** 退出 FT8。

**Tab 菜单的第一项是 Auto CQ，下面依次有 Bands、Call CQ、POTA Hunt、Settings 等。** Bands 用于切换 FT8 波段。不要把主菜单的 Settings（连接与更新）和 FT8 的 Settings（呼号、网格、发射与日志偏好）混淆。

### Auto CQ 和 POTA Hunt

- **Auto CQ**：先发一次自己的 CQ。如果无人回答，依次尝试最多五个近期、较强的 CQ 目标，每个先呼叫两次。交换有进展后进入正常通联流程，每个阶段最多允许四次无进一步回复的发送。其他电台在交换期间呼叫你时会进入队列。完成或放弃一个联系后继续处理队列或开始下一轮，直到没有合适回复/目标、手动停止或出现故障。
- **POTA Hunt**：等待含 POTA/SOTA 标记的 CQ，按其特殊流程从 R 信号报告开始尝试；通常每阶段三次无回复后休息，RRR 阶段允许四次。它不会先发送自己的 CQ。

普通通联使用 **RRR**，并以 **73** 完成；接收 **RR73** 也可以推进流程。完成后的对方再次发送 RRR/RR73 时，已启用的发送序列可以补发 73，而不重复记录同一 QSO。

底部的**红点**表示发送序列已启用，接收时隙也可能亮着；**红色 TX** 表示电台当前正在发射，包括天调。功率设定不一定等于仪表实际读数，应同时观察电台上的 Po、SWR 和 ALC。SWR、ALC、PTT、校时或连接异常会停止发送；修正原因后按 **Enter** 请求清除警告，再手动重新开始，不会自动恢复发射。

## 主菜单 Log 日志本

选择主菜单的 **Log**，即可浏览设备中的完整通联日志，不需要连接电台。F/X 或方向键浏览，Enter 查看 UTC 时间、频率、模式、信号报告和上传状态，Tab 打开菜单。

- **New entry**：手动添加已完成的通联，填写对方呼号、UTC 日期/时间、MHz 频率、模式、实际信号报告及可选网格/备注。此操作不会发射。
- **Search callsign**：按呼号搜索；清空搜索后恢复全部记录。
- **Sync logs**：选择已配置并启用的 Wavelog 或 QRZ，再选择 Start sync。先下载完整通联到设备，匹配已有记录，再将选定服务中缺少的本地通联加入上传队列。不会删除或覆盖已有记录。
- **Station & logging**：设置自己的呼号、网格和服务账号；主菜单 **Settings → Station & logging** 也有同一入口，与 FT8 共用配置。

此完整日志同步与 FT8 原有的 **Sync Log**（仅下载已通联索引，用于隐藏老朋友）不同。完整导入也会更新 FT8 已通联索引。下载按页保存进度；退出 Log 后停止继续下载，下次同步可继续。重复同步不会重复添加匹配的通联，但本版不会同步覆盖远端对旧记录的修改/确认状态。无效或属于其他本站呼号的记录会跳过并显示数量；上传排队不代表网站已收到。

## 日志与历史同步

成功完成的 QSO 会先保存在本地。绿色提示框表示本地已保存，不代表远程网站已经接收。

在 FT8 的 **Tab → Logging** 中设置：

- **Wavelog**：填写 **API URL**、**API key**、**Station ID**，并启用 **Enabled**。URL 使用自己的 HTTPS 地址，如 `https://log.example.com/index.php`。API key 需要相应的读写权限。Station ID 留空时，**Test connections** 可查找与呼号/网格匹配的电台配置。
- **QRZ**：填写自己的日志 API key 并启用 **Enabled**。API 功能可能需要相应的 QRZ 订阅。若希望两个服务都有记录，请分别配置；不要假设 Wavelog 会转发 API 创建的记录到 QRZ。
- **Test connections**：检查连接，只读取信息，不创建测试通联。
- **Sync pending**：重试尚未成功上传的日志。
- **Local log**：查看本地已完成通联。
- **Sync Log**：从 Wavelog 或 QRZ 下载已通联历史，供隐藏/筛选使用；不会把导入历史全部复制到 Local log。

将 **Settings → Hide previous contacts** 设为开启后，只隐藏**当前波段、FT8 模式**中已联系过的电台。Auto CQ 仍可回复或排队处理主动呼叫你的老朋友。外部软件新做的通联可再运行 Sync Log 更新。

若通联已经完成但未自动记录，可以选中对方解码，进入 **Tab → Record QSO**，核对呼号、网格以及实际交换的信号报告后保存。不要为未收到的报告编造数值。

请勿在公开讨论、截图或 GitHub 文件中粘贴电台密码、Wavelog/QRZ API key。应用将个人配置和日志保存在设备上，不会随公开安装包附带。

## 外网远程连接

先完成局域网测试。若使用 IC-7300MK2 的默认端口，在电台所在路由器中将 **UDP 50001、50002、50003** 转发到电台的固定局域网 IP，外部与内部端口号保持一致。ICOMzero 的频谱数据通过 CAT 通道传输，不需要另开 50004。

克隆一个电台配置，命名为远程配置，将 **Host** 改为家中公网 IP 或域名，再选择 **Use this radio**。电台默认网关必须正确。也可以通过能路由到电台局域网的 VPN 访问。公网访问还取决于路由器、防火墙和运营商是否提供可入站访问的地址。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 停在 Finding radio / 无法连接 | 核对 Host、同一局域网是否可达、Network Control、用户名/密码和端口；确认没有另一个 LAN 客户端占用电台。不要把其他 Icom 机型配置误选为原版 IC-7300 |
| 反复重连 | 先排查 Wi-Fi 和 IP 地址变化；为电台保留 DHCP 地址。应用会有界重试，请同时查看屏幕给出的具体错误 |
| Radio 有连接但没有声音 | 检查 Fn+A 是否静音、Fn+D 调大音量；FT8 页面静音则属于正常情况 |
| 频谱空白 | 检查电台是否提供/开启网络频谱数据；不同机型能力不同。缩放只放大已有数据，不会产生新数据 |
| CW 字符不准确 | 换到清晰 CW 信号，检查模式和音调，必要时手动选 CW tone；不要将 RTTY 当作 CW |
| FT8 提示时钟未同步 | 让设备能访问网络时间服务；可通过 SSH 用 `timedatectl status` 检查同步状态。设备所在时区不影响 FT8 使用 UTC 时隙，但时钟本身必须准确 |
| SWR / ALC / PTT 警告 | 先核对天线、天调、功率和音频电平，并观察电台仪表；修复后按 Enter 请求清除。不要反复清除同一个未解决的故障 |
| 从 ICOMzero 换回 USB 连接的 WSJT-X 没有发射音频 | 确认 ICOMzero 已退出且电台处于接收，再核对电台的 DATA MOD 等音频输入是否适合 USB。ICOMzero 的网络发射使用 LAN 音频输入；USB 软件需要相应的 USB 输入设置 |
| 本地有 QSO，网站没有 | 检查 API 配置、服务是否 Enabled，以及上传状态，再用 Sync pending 重试 |

## 更新应用

在主菜单选择 **Settings → Check for updates**。有更新时按界面提示下载；应用会验证 SHA-256，并在安装时询问 **Cardputer 设备管理员密码**，不是电台密码或 API key。安装完成后关闭并重新打开应用。

也可以在 App Store 中更新。更新保留电台配置和 QSO 历史。**Launch update check** 控制是否在启动时检查 GitHub 更新。

如仍有问题，请在 [GitHub Issues](https://github.com/unagisan69/ICOMzero/issues) 或 [App Store 讨论区](https://github.com/CardputerZero/cardputerzero.github.io/discussions/51) 描述电台型号、应用版本、局域网/外网连接方式及屏幕错误原文；请先移除密码、API key 等私密信息。
